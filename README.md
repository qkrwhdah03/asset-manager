# 개인 자산 관리 (Asset Manager)

Windows 10/11용 개인 자산 관리 프로그램입니다. **월별 현금흐름(수입·지출 계획·실제 지출) + 자산·계좌 관리 + 경제·금융 지표 추적**을 하나의 프로그램에서 처리합니다.
모든 데이터는 내 PC의 SQLite 파일에 저장되며, 인터넷 연결이나 외부 API 없이도 모든 핵심 기능이 동작합니다.

> **현재 메뉴 구성**: 대시보드 · 월 예산(수입·지출) · 설정 및 데이터.
> 자산 관리·지표 추적(및 외부 금융 API 연동)은 추후 다시 추가할 예정이라 **화면에서만 숨겨 두었습니다.**
> 관련 코드(`app/services/assets.py`, `indicators.py`, `providers/`, `app/static/js/pages/assets.js`, `indicators.js`)와
> 저장된 데이터·테스트는 그대로 남아 있으며, `app/static/js/app.js`의 메뉴 목록에 다시 넣으면 복구됩니다.

## 빠른 시작 (Windows)

준비물: [Python 3.11 이상](https://www.python.org/downloads/) (설치 시 "Add python.exe to PATH" 체크)

1. `setup.bat` 더블클릭 → 가상환경(`.venv`) 생성 및 패키지 설치 (최초 1회)
2. `run.bat` 더블클릭 → 데스크톱 창으로 실행

명령 프롬프트에서 직접 실행하려면:

```bat
cd C:\Users\qkrwh\Claude\asset-manager
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m app.main
```

| 명령 | 설명 |
|---|---|
| `.venv\Scripts\python -m app.main` | 데스크톱 창(Edge WebView2)으로 실행 |
| `.venv\Scripts\python -m app.main --browser` | 기본 브라우저로 실행 (창 모드가 안 될 때) |
| `.venv\Scripts\python -m app.main --port 8765 --no-open` | 서버만 실행 → http://127.0.0.1:8765 |
| `test.bat` 또는 `.venv\Scripts\python -m pytest -q` | 테스트 실행 |
| `build.bat` | 테스트 후 `dist\AssetManager\AssetManager.exe` 생성 (Python 없는 PC에서 실행 가능) |

### 데이터 위치

- 기본: `%LOCALAPPDATA%\AssetManager\asset_manager.db` (예: `C:\Users\<사용자>\AppData\Local\AssetManager`)
- 백업: 같은 폴더의 `backups\`, CSV 내보내기(데스크톱 창): `exports\`, 로그: `app.log`
- 다른 위치를 쓰려면 환경 변수 `ASSET_MANAGER_DATA_DIR` 지정 (예: USB 포터블 사용)
- 프로그램 폴더를 지우거나 새 버전으로 바꿔도 데이터는 유지됩니다.

## 기술 스택과 선택 이유

| 구성 | 선택 | 이유 |
|---|---|---|
| 백엔드 | Python 3.11+ · FastAPI · 표준 `sqlite3` | 통계·금액 계산을 `Decimal`/정수로 정확하게 처리, 테스트 작성이 쉬움, 의존성 최소 |
| 저장소 | SQLite (WAL, 외래키 ON) | 설치 불필요한 단일 파일 DB, 백업·복원 단순, 참조 무결성 지원 |
| UI | HTML/CSS + Preact(htm) + Chart.js — **로컬 동봉** | 빌드 도구 없이 동작, 인터넷 없이도 차트·UI 사용 가능, 표 중심 고밀도 UI를 빠르게 구현 |
| 데스크톱 창 | pywebview (Windows 기본 Edge WebView2) | 브라우저 탭이 아닌 독립 창. 실패 시 기본 브라우저로 자동 대체 |
| 배포 | PyInstaller | Python 미설치 PC용 실행 파일 폴더 생성 |

## 데이터 모델

| 테이블 | 내용 |
|---|---|
| `categories` | 항목(모든 달 공통). `kind`(income=소득 / expense=지출), 색상, `memo`(설명), 정렬 순서 |
| `records` | 수입·계획·지출 기록. `kind`(income/plan/expense), `category_id`, `amount`(원 정수), `month`(월: 수입=입금 월, 계획=계획 월, 지출=발생 월), `txn_date`(수입=실제 입금일 / 지출=발생일), `settle_date`(지출 결제일), `item`(세부항목 이름), `budget_month`(수입의 예산 월), `tag`(시스템 조정: move=계획 옮기기, settle=월말 정산), `memo` |
| `asset_types` | 자산 유형. 평가 방식(잔액 / 수량×가격), 성격(현금성·투자·기타) |
| `accounts` | 계좌·보유 수단. 유형, 금융기관, 입력 방식(수동/CSV/API), 사용 여부 |
| `securities`, `security_prices` | 종목과 일자별 시세 |
| `asset_txns` | 자산 변동: 입금·출금·이체·매수·매도·배당·이자·수수료·평가액 변동·기타 조정 |
| `indicators`, `indicator_values` | 지표 정의(출처·주기·수집 방식)와 일자별 값(값마다 출처 기록) |
| `settings` | API 키 등 로컬 설정 |

- **금액은 원 단위 정수**로 저장(부동소수 오차 없음). 주식 수량·단가는 소수 허용을 위해 Decimal 문자열.
- 항목·계좌는 id로 참조하므로 이름을 바꿔도 기존 기록이 유지됩니다. 항목은 비활성화 없이 삭제만 합니다(기록이 있으면 확인 후 기록까지 삭제). 계좌는 기록이 있으면 비활성화됩니다(자산 기능, 현재 숨김).
- 스키마 변경은 `db.MIGRATIONS`에 추가하며, 기존 DB를 업그레이드하기 전 자동 백업(`pre_migration_*.db`)을 남깁니다.

## 주요 기능과 계산 정의

### 월 예산 (수입·지출)
들어온 돈을 계획대로 쓰는지 확인하는 화면입니다. 순서는 **① 소득 → ② 배분(지출 계획) → ③ 지출(세부항목) → ④ 정산**입니다.

- **항목 = 모든 달 공통**: 설정 → 항목에서 소득 항목(급여, 장학금 …)과 지출 항목(식비, 교통비, 저축·투자 …)을
  만들고, 이름 변경·드래그로 순서 변경·✕ 삭제를 합니다. 모든 달에 같은 순서로 표시됩니다.
- **소득 세부항목 = 그 달의 기록**: 소득 항목 줄에 마우스를 올려 **+ 세부항목**을 누르고 이름·금액·입금일을 입력합니다.
  달마다 달라도 되며(예: 장학금 > 국가장학금), 항목 줄에는 세부항목 합계가 표시됩니다.
  칸을 벗어나면 자동 저장되고, Enter는 같은 줄의 다음 칸으로 이동합니다. 항목 이름 앞 ▾/▸ 로 접고 펼 수 있습니다.
- **삭제**: 세부항목은 줄의 ✕ 또는 체크박스 선택 후 '선택 삭제'로 지웁니다(그 달의 기록만 삭제).
  항목을 지우면(설정) 그 항목의 모든 기록도 함께 삭제되며, 기록 수를 보여 주고 확인을 받습니다.
- **① 소득**: 입금일이 비어 있으면 '미입금'. 표에서 입력한 소득은 지금 보는 달에 쓸 돈(예산 월)이 됩니다.
- **② 배분**: 지출 계획은 **항목 단위**로 입력합니다. 오른쪽 카드의 `쓸 돈 − 계획 = 아직 배분 안 된 돈`이 0원이 될 때까지 나눕니다.
  월 선택 옆 '지난달 불러오기'로 지난달 내용을 가져올 수 있습니다. **[항목]**은 소득 세부항목 이름, **[금액]**은 소득 세부항목 금액과 지출 계획 금액입니다.
- **③ 지출**: 소득과 같은 방식입니다. 지출 항목 줄의 [+ 세부항목]으로 쓴 돈을 이름·금액·**지출일**로 기록합니다.
  ② 계획 표의 **실제**는 세부항목 합계로 자동 계산되고, 남음(계획 − 실제)과 진행 막대(세로선 = 오늘)가 바로 바뀝니다. 막대 아래에는 사용률과 남은 날 동안 하루에 쓸 수 있는 금액(초과면 초과 금액)이 나옵니다. 월말 정산 금액은 '월말 정산' 줄로 따로 보입니다.
  초과한 항목은 **메우기**로 다른 항목(또는 미배분)의 계획을 옮겨 옵니다.
- **④ 정산**: 월말에 남은 돈을 한 항목으로 보내 **소득 = 계획 = 지출**로 마감합니다.
  원래 계획은 보존되며(계획 옆 `*`), '정산 취소'로 되돌릴 수 있습니다.
  정산 후 기록을 고치면 '다시 정산'으로 지금 기록에 맞춰 한 번에 다시 정산합니다(대상 항목은 지난 정산과 같음).

### 대시보드
- 월 예산과 같은 기준으로 집계합니다(소득은 예산 월, 지출은 그 달). 이번 달 수입, 실제 지출, **저축액 = 수입 − 실제 지출**(현금흐름 기준), 계획 대비 초과/절약.
- 월별 수입·지출 추이(최근 6/12개월, 연도), 저축액·저축률, 항목별 지출 비중, 계획 대비 실제, 연간 요약.
- 막대·조각·카드를 클릭하면 해당 월/항목 기록으로 이동합니다.

> 저축액(현금흐름)은 기록한 수입·지출의 차이이며, 자산 페이지의 '자산 증감'(계좌 잔액 변화)과 다를 수 있습니다. 두 값은 별도로 표시됩니다.

### 자산 관리 (현재 숨김 · 추후 추가 예정)
- 계좌(현금, 은행 계좌, 증권 계좌 등)를 유형별로 등록. 기존 잔액은 **입금**(또는 기타 조정)으로, 보유 주식은 입금 후 **매수**로 입력합니다.
- **평가액** = 현금 잔액 + 평가액 변동 누계 + Σ(보유 수량 × 기준일 시세). 시세가 없으면 최근 거래 단가를 사용(표시됨).
- **순투입원금** = 입금 − 출금 + 기타 조정. **계좌 간 이체는 전체 자산 기준에서 수익·지출로 잡히지 않습니다.**
- **투자 손익** = 평가액 − 순투입원금 = 실현손익 + 평가손익 + 배당 + 이자 − 수수료 + 평가액 변동 (테스트로 항등식 검증)
- **자산 증감** = 순유입 + 투자 손익 → 자산 증가와 투자 수익을 분리해서 표시합니다.
- 매수 수수료는 취득원가에 포함, 매도 시 이동평균 단가로 실현손익 계산. 보유 수량을 초과하는 매도는(과거 시점 포함) 거부됩니다.
- 통계: 총자산, 유형별 비중, 계좌별 잔액·수익률, 월별 총자산(현금성/투자/기타), 월별 증감 분해, 계좌별 평가액 추이, 월 수익률(Modified Dietz 근사).

### 지표 추적 (현재 숨김 · 추후 추가 예정)
- 지표명·단위·출처·출처 URL·업데이트 주기·수집 방식(수동/ECOS/FRED)을 정의하고, 현재값·이전값 대비 변화·최근 업데이트·시계열 그래프를 표시합니다.
- 프리셋: 한국 기준금리, 원/달러 환율, 소비자물가지수, KOSPI, 국고채 3년(ECOS) / S&P 500, 미국 10년 국채, 연방기금금리, 미국 CPI(FRED). **프리셋은 정의만 추가하며 값은 넣지 않습니다.**
- 값은 공식 API, CSV, 수동 입력으로만 들어오고, 출처가 함께 저장됩니다. 임의 생성 데이터는 표시하지 않습니다.

### 설정 및 데이터 관리
- **항목**: 소득·지출 항목 추가, 색·이름·메모(어떤 항목인지) 변경, 드래그로 순서 변경, 삭제(기록도 함께 삭제, 확인 후).
  메모는 월 예산에서 항목 이름에 마우스를 올리면 보입니다.
- **기록 옮기기(합치기·나누기)**: 항목 줄의 '옮기기'를 누르면 그 항목의 모든 달 기록이 목록으로 나옵니다.
  전부 골라 다른 항목으로 옮기면 **합치기**(비게 된 항목은 지울지 물어봄), 일부만 옮기면 **나누기**이며,
  옮길 곳에서 '+ 새 항목 만들기'를 고르면 새 항목을 만들면서 옮깁니다. 기록을 지우지 않으므로 월별 합계는 그대로입니다.
  월 예산의 소득 표에서도 세부항목을 체크해 '선택 옮기기'로 옮길 수 있습니다.
- **삭제 백업 규칙(모든 삭제 공통)**: 0원이 아닌 기록이 하나라도 함께 지워지면 직전에 자동 백업(`pre_delete_*.db`)을 만듭니다. 이 자동 백업은 최근 30개만 남깁니다.
- **백업**: '지금 백업' → `backups\manual_*.db`. 목록에서 다운로드·복원·삭제, 외부 `.db` 파일에서 복원.
  복원 전 SQLite 무결성·스키마 버전·필수 테이블을 검사하고 현재 데이터를 `pre_restore_*.db`로 자동 보관합니다.
- **초기화**: 설정 → 백업·복원 → 초기화. '기록만 지우기'는 항목을 남기고 모든 기록을 지우고, '처음 상태로'는 기본 항목만 있는 새 데이터로 되돌립니다. 지우기 전에 `pre_reset_*.db`로 자동 백업합니다.
- **CSV 가져오기**(수입·지출 기록 / 자산 변동 / 종목 시세 / 지표 값): 먼저 검증(미리보기)하고, 오류가 하나라도 있으면 행 번호와 이유를 보여 주며 **아무것도 저장하지 않습니다.** UTF-8·CP949 모두 지원. 예시 양식 제공.
- **CSV 내보내기**: Excel에서 바로 열리는 UTF-8(BOM).

## 알려진 제한

- 외화 자산(USD 주식 등)은 원화로 환산한 단가를 직접 입력해야 합니다(환율 자동 반영 없음).
- 종목을 다른 계좌로 '현물 이체'하는 기능은 없습니다(매도/매수로 기록).
- API 키는 로컬 DB에 평문으로 저장됩니다(백업 파일에도 포함). PC 계정 보안에 의존합니다.
- 데스크톱 창 모드에서 CSV 내보내기는 다운로드 대신 데이터 폴더의 `exports\`에 저장되고 폴더가 열립니다.
