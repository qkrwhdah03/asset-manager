# 외부 금융·경제 데이터 연동 조사 (2026-10 기준)

원칙: 공식 API 또는 정식 허용된 방식만 사용한다. 개인 사용자가 실제로 접근할 수 없는 연동은 구현하지 않고, 수동 입력과 CSV 가져오기로 대체한다.
인증키는 소스 코드에 넣지 않고 사용자가 설정 화면에서 입력하며 로컬 DB에만 저장한다. 계좌 데이터는 외부로 전송하지 않는다.

## 1. 지표 데이터

### 한국은행 ECOS Open API — 구현함
- 주소: https://ecos.bok.or.kr/api/ (인증키 무료 신청, 개인 가능)
- 호출 형식: `/api/StatisticSearch/{인증키}/json/kr/{시작}/{끝}/{통계표코드}/{주기}/{검색시작}/{검색끝}/{항목코드1}/...`
  - 주기: D(일, YYYYMMDD) / M(월, YYYYMM) / Q(분기, YYYYQn) / A(연, YYYY)
  - 오류: `{"RESULT": {"CODE": "...", "MESSAGE": "..."}}`, `INFO-200` = 데이터 없음
- 항목 확인: `/api/StatisticItemList/{인증키}/json/kr/1/500/{통계표코드}` → 프로그램의 지표 설정 화면 **'항목 조회'** 버튼으로 사용
- 프리셋에 넣은 통계표·항목코드(722Y001 기준금리, 731Y001 환율, 901Y009 CPI, 802Y001 KOSPI, 817Y002 국고채)는
  **공식 문서로 재확인이 필요**하다. 공개 자료 검색에서 722Y001(기준금리)만 교차 확인됐고, 731Y001 등은 일부 자료에서 다른 통계표로 소개되기도 했다.
  잘못된 코드면 ECOS가 오류를 반환하고 프로그램은 오류를 표시할 뿐 값을 만들지 않는다. 지표 설정에서 코드를 수정할 수 있다.
- 검증 상태: URL 생성·응답 파싱·오류 처리는 단위 테스트로 검증. **실제 인증키로의 호출은 이 개발 환경에서 검증하지 못함.**

### FRED (St. Louis Fed) — 구현함
- 주소: https://fred.stlouisfed.org/docs/api/fred/ (API 키 무료 발급)
- `series/observations?series_id=SP500&api_key=...&file_type=json&observation_start=YYYY-MM-DD`, 결측치는 `"."`
- 프리셋: SP500(S&P 500), DGS10(미국 10년 국채), DFF(실효 연방기금금리), CPIAUCSL(미국 CPI)
- 참고: SP500 시리즈는 S&P Dow Jones Indices 라이선스로 최근 10년 범위만 제공된다.
- 검증 상태: ECOS와 동일(파싱 테스트 완료, 실제 키 호출 미검증).

### 공공데이터포털(data.go.kr)
- 금융위원회 '주식시세정보', '지수시세정보' 등 일 단위(전일 기준) 시세 API가 있으나, 활용 신청·승인과 서비스별 키가 필요하고 서비스 사양이 자주 바뀐다.
- 이번 버전에서는 구현하지 않음. 추가 시 `app/services/providers/`에 공급자 모듈을 추가하는 구조로 확장 가능.

## 2. 계좌·잔고 데이터

### 카카오페이증권
- 개인 투자자가 자신의 계좌·잔고를 조회할 수 있는 **공개 Open API를 확인하지 못함**(2026-10 검색 기준). 일부 증권사(예: 한국투자증권 KIS Developers)는 개인용 Open API를 제공하지만 카카오페이증권은 해당 사례를 찾지 못했다.
- 비공식 스크래핑·앱 리버스엔지니어링은 약관 위반 소지와 계정 보안 위험이 있어 사용하지 않는다.
- **대체**: 앱/웹에서 거래내역을 내려받거나 옮겨 적은 CSV를 '자산 변동' 양식(날짜, 유형, 계좌, 종목코드, 수량, 단가, 금액, 수수료)으로 가져오기.

### 은행 계좌·예적금
- 금융결제원 오픈뱅킹은 이용기관(핀테크 사업자) 등록이 필요하고, 마이데이터(본인신용정보관리업)는 금융위원회 허가 사업자만 정보를 수집할 수 있다. 개인 개발자가 자기 계좌용으로 직접 이용할 수 있는 경로가 아니다.
- **대체**: 수동 잔액 입력(입금/출금/이자), 거래내역 CSV 가져오기.

## 3. 주식·ETF 시세
- 무료이면서 개인이 사용할 수 있는 공식 실시간 시세 API를 확보하지 못함. 증권사 Open API(KIS 등)는 해당 증권사 계좌가 필요.
- **대체**: '보유 종목·시세' 탭에서 종가 수동 입력, 또는 `날짜,종목코드,가격` CSV 가져오기.
- 확장 지점: 시세 공급자를 추가하면 `security_prices`에 `source`를 붙여 저장하는 동일 구조로 연결 가능.

## 4. 장애 시 동작
- API 키 없음·네트워크 오류·인증 실패·잘못된 코드 → 지표에 `last_error`를 기록하고 화면에 표시. 기존 값은 그대로 유지되며, 수동/CSV 입력은 항상 가능.
- 모든 API 호출은 사용자가 '가져오기/전체 업데이트'를 누를 때만 실행된다(백그라운드 자동 호출 없음).
